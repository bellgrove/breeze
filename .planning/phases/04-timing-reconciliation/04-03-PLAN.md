  <behavior>
    - writeBatch(ctx, pool, batch, delay) finds min(SizerTime) across the batch, calls resolveGrademapID, sets GrademapID on each fruit row
    - If resolveGrademapID returns err, log a warning and write fruit with GrademapID=nil (non-fatal)
    - If resolveGrademapID returns ok=false (no rows), write fruit with GrademapID=nil (correct: no grademap yet)
    - flushBuffer(ctx, pool, buf, delay) passes delay through to writeBatch (or replicates the resolve+set logic)
    - run() parses GrademapPropagationDelayStr at startup; empty string → zero duration (no offset); invalid string → return error
    - run() passes propagationDelay to writeBatch and flushBuffer at every call site
    - TestWriteBatch_GrademapID (Wave 0 stub) now passes: updated signature compiles, closed pool returns error
  </behavior>
  <action>
    1. Update `writeBatch` signature to:
       ```go
       func writeBatch(ctx context.Context, pool *pgxpool.Pool, batch []processor.Fruit, delay time.Duration) error
       ```

       At the start of writeBatch, before building rows, resolve the grademap ID:
       ```go
       var grademapID *int64
       if len(batch) > 0 {
           // Use the earliest SizerTime in the batch as the anchor (conservative)
           anchor := batch[0].SizerTime
           for _, f := range batch[1:] {
               if f.SizerTime.Before(anchor) {
                   anchor = f.SizerTime
               }
           }
           id, ok, err := resolveGrademapID(ctx, pool, anchor, delay)
           if err != nil {
               slog.Warn("Failed to resolve grademap ID — writing fruit with NULL grademap_id", "err", err)
           } else if ok {
               grademapID = &id
           }
       }
       ```

       Then when building rows, set `batch[i].GrademapID = grademapID` before calling `AsRow()`:
       ```go
       for i := range batch {
           batch[i].GrademapID = grademapID
           row, err := batch[i].AsRow()
           ...
       }
       ```

    2. Update `flushBuffer` signature to:
       ```go
       func flushBuffer(ctx context.Context, pool *pgxpool.Pool, buf []processor.Fruit, delay time.Duration) error
       ```
       Apply the same grademap resolution logic as writeBatch (copy the anchor-finding + resolveGrademapID block).

    3. In `run()`, after applying config defaults, add delay parsing:
       ```go
       var propagationDelay time.Duration
       if cfg.GrademapPropagationDelayStr != "" {
           propagationDelay, err = time.ParseDuration(cfg.GrademapPropagationDelayStr)
           if err != nil {
               return fmt.Errorf("invalid grademap_propagation_delay %q: %w", cfg.GrademapPropagationDelayStr, err)
           }
       }
       // zero value means no adjustment — correct
       ```

    4. Update all call sites in `run()` to pass `propagationDelay`:
       - `writeBatch(ctx, pool, batch, propagationDelay)`
       - `flushBuffer(ctx, pool, writeBuffer, propagationDelay)`

    Anti-patterns to avoid:
    - Do NOT query resolveGrademapID inside the CopyFrom loop — pgx does not support this
    - Do NOT make grademap failure a fatal error — fruit must still be written with NULL
    - Do NOT use time.Now() as the anchor — use fruit.SizerTime (OEM processing time)
    - Do NOT treat zero delay as "unset" — zero duration is explicitly valid (no adjustment)
