<objective>
Close two high-priority tech debt items flagged by the v1.0 milestone audit.

Fix 1 (QUAL-01): The timer send inside OnMessage is blocking. `p.timer <- true` at processor.go line 57 sits inside the `case p.queue <- f:` branch. The timer channel is created with capacity 1 in `Create()`. When the batch goroutine hasn't consumed the previous signal during a rapid message burst, a second OnMessage call blocks on this send — stalling the paho MQTT dispatcher. Wrap the timer send in a `select/default`.

Fix 2 (QUAL-05): `ValidateFruit` in fruit_test.go calls `field1.Equal(field2)` for all non-slice struct fields. Eight `Fruit` fields have Kind `reflect.Map` (`MCenterOffsets`, `MClassifiedBlob`, `MColour`, `MColourBlob`, `MDiameters`, `MFeatures`, `MFunction`, `MTimer`). `reflect.Value.Equal` panics on map kinds — this causes `TestFromJson/Class_2` to panic. Add a `reflect.Map` guard that routes map fields through `reflect.DeepEqual`.

Purpose: Production reliability (QUAL-01) and clean test infrastructure (QUAL-05). `go test ./...` must exit 0.
Output: Two edited files + one new test function. No new dependencies.
</objective>
